# coi-image.sh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a management script `coi-image.sh` and a provisioning script `coi-build.sh` to automate the creation and management of a Flutter/Android/OpenCode development environment using `coi`.

**Architecture:** A two-script approach where `coi-image.sh` runs on the host to manage the container lifecycle via `coi`, and `coi-build.sh` runs inside the container during the build process to install and configure all dependencies.

**Tech Stack:** Bash, `coi` (Code-on-Incus), Flutter SDK, Android SDK, OpenCode, RTK, Superpowers.

- [ ] **Step 2: Add Flutter and Android SDK installation to `coi-build.sh`**

```bash
echo "Installing Flutter SDK..."
mkdir -p /opt/flutter
curl -fsSL https://storage.googleapis.com/flutter_infra_release/releases/stable/linux/flutter_linux_3.24.3-stable.tar.xz | tar -xJ -C /opt/flutter --strip-components=1
echo 'export PATH="$PATH:/opt/flutter/bin"' >> /etc/bash.bashrc
export PATH="$PATH:/opt/flutter/bin"
flutter config --no-analytics

echo "Installing Android SDK..."
mkdir -p /opt/android-sdk/cmdline-tools
curl -fsSL https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip -o /tmp/cmdline-tools.zip
unzip /tmp/cmdline-tools.zip -d /opt/android-sdk/cmdline-tools
mv /opt/android-sdk/cmdline-tools/cmdline-tools /opt/android-sdk/cmdline-tools/latest
rm /tmp/cmdline-tools.zip

echo 'export ANDROID_HOME=/opt/android-sdk' >> /etc/bash.bashrc
echo 'export PATH="$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools"' >> /etc/bash.bashrc
export ANDROID_HOME=/opt/android-sdk
export PATH="$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools"

yes | sdkmanager --licenses
sdkmanager "platforms;android-35" "build-tools;35.0.0" "platform-tools"
```

- [ ] **Step 3: Add OpenCode, RTK, and Superpowers setup to `coi-build.sh`**

```bash

echo "Installing RTK..."
```

### Task 2: Create `coi-image.sh` (Management Script)

**Files:**
- Create: `coi-image.sh`

- [ ] **Step 1: Write `coi-image.sh` with build, shell, list, and delete commands**

```bash
#!/bin/bash

IMAGE_NAME="mneme-dev"

case "$1" in
  build)
    echo "Building image $IMAGE_NAME..."
    coi build custom "$IMAGE_NAME" --script coi-build.sh
    ;;
  shell)
    echo "Starting shell in $IMAGE_NAME..."
    coi shell --image "$IMAGE_NAME"
    ;;
  list)
    coi image list --prefix mneme-
    ;;
  delete)
    echo "Deleting image $IMAGE_NAME..."
    coi image delete "$IMAGE_NAME"
    ;;
  *)
    echo "Usage: $0 {build|shell|list|delete}"
    exit 1
    ;;
esac
```

Run: `chmod +x coi-image.sh`
